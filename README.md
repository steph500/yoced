# YOCED

New website for **Youth Corporate and Economic Development (YOCED)**.

## Direction

The site is built as an **Impact Atlas** rather than a conventional NGO brochure. It gives youth, communities, funders, partners and collaborators direct routes into the exact YOCED field relevant to them while preserving a complete view of the wider ecosystem.

## Stack

- Next.js App Router
- React
- TypeScript
- Motion for interaction and scroll animation
- Lucide icons
- Custom CSS design system

## Core routes

- `/` overall YOCED ecosystem
- `/programs` searchable program directory
- `/programs/[slug]` shareable field-specific program pages
- `/ventures` active ventures
- `/partners` funder and partner pathway
- `/about` organization and leadership
- `/contact` direct routing into YOCED

## Content basis

The first rebuild is based on YOCED's recovered historical website screenshots, Gmail correspondence, proposals, program documents and confirmed current direction. Current project photography from the local YOCED photo archive should be added as the next content pass.
